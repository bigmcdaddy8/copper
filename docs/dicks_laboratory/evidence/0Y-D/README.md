# 0Y-D evidence — Blind multi-day day-type validation

Design and assessment: `../../MARKET_PROFILE_VALIDATION_0YD.md`. Corpus:
`../../MARKET_PROFILE_CORPUS_0YD.md`.
- Runs were offline and read-only.
- All 22 databases' sha256 values were unchanged by the blind run.
- The frozen V1 policy code is unchanged since `fbbb095`.

| Path | What |
|---|---|
| `blind_run/records.jsonl` + `records.sha256` | The frozen blind run, one `DayRecord` per dataset. sha256 `b15fef0c059b0c2cf4f4368579aa4c3c8d881ceec177ccbc0fe3baa38ce5ae4e` |
| `blind_run/reports/<TD>_<id>.txt` | Raw render per dataset: TPO matrix, 0Y-B structure, 0Y-C day structure with every condition. Inspection profiles for the shortlist. |
| `blind_run/validation_report.md` | Generated by `analyze` from the frozen records: inventory, distribution, boundary proximity, per-type sensitivity, outliers, shortlist |
| `blind_run/timings.tsv` | Per-dataset wall time; 1,385 s in total |
| `hypothesis_whatif.py` + `_output.md` | What-if counts for the follow-up hypotheses H1–H3 (diagnostic only; nothing adopted) |

Reproduce from the repo root:

```
uv run python scripts/dicks_lab_mp_validation.py run OUT ~/secure/mp_corpus/*.sqlite3 <local paths listed in the corpus doc>
uv run python scripts/dicks_lab_mp_validation.py analyze OUT
```
